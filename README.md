# Einmaleins

Das Einmaleins der Reihen 3 bis 9 – lernen und üben (Mal-, Geteilt- und Lücken-Aufgaben), fürs iPad, iPhone und den PC.
Läuft auch ohne Internet (Safari → Teilen → »Zum Home-Bildschirm«).

Dieser Ordner wird von `Scripts/bauen.py` im Projekt `Einmaleins` erzeugt – hier nichts von Hand ändern, es wird überschrieben.
